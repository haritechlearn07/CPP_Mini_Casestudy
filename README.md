🎓 Academic Problem Monitoring and Management System (APMMS)

A C++ based console application developed by Group 12 to collect, store, search, and manage academic problems reported by students.

📌 About the Project

APMMS provides a centralized platform for recording academic problems across different Blocks, Years, and Sections. The system uses C++ file handling to maintain persistent records in "problems.txt".

🚀 Features

- ➕ Add academic problems
- 📋 View all recorded problems
- 🔍 Search problems by Block and Year
- 💾 Persistent file-based storage
- 🖥️ Menu-driven console interface
- ⚠️ Handles invalid menu choices
- 📂 Supports 8 Blocks, 4 Years, and 4 Sections

🛠️ Technologies Used

- C++
- File Handling
- Structures
- Functions
- Loops
- Switch-Case
- Console Interface

⚙️ Main Modules

1. Add Problem

Students enter their Block, Year, Section, and problem description. The information is stored in "problems.txt".

2. View Problems

Displays all stored academic problems.

3. Search Problems

Searches for problems based on Block and Year.

4. Main Controller

Provides the menu and controls the different operations using a switch-case structure.

▶️ How to Run

Compile the program:

g++ APMMS.cpp -o APMMS

Run:

./APMMS
